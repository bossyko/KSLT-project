# KSLT — E2E tests

Девятнадцать наборов проверок разложены по пяти папкам. Деление —
по тому, **что** проверяется, а не по тому, как написано.

```
tests/e2e/
  ui/              что человек видит
  ux/              как оно себя ведёт
  design-system/   целостность стилей
  features/        функционал
  platform/        PWA, поиск, приложение
```

---

## ui/ — что человек видит

Страница открылась, элементы на месте, ссылки ведут куда надо.

| Файл | Что проверяет |
|---|---|
| `01-pages-load.spec.js` | все публичные страницы открываются, ключевые элементы на месте |
| `02-navigation.spec.js` | шапка, переключение языка, подвал, внутренние ссылки без битых |
| `06-homepage-sections.spec.js` | секции главной страницы |
| `09-content-pages.spec.js` | контентные страницы: оферта, условия, политика, инфо |
| `18-partials.spec.js` | партиалы разнесены по страницам и совпадают с исходником |

## ux/ — как оно себя ведёт

Поведение при смене экрана и при работе пальцем, а не мышью.

| Файл | Что проверяет |
|---|---|
| `03-responsive.spec.js` | нет горизонтальной прокрутки, бургер на мобильном, читаемость, картинки |
| `19-footer-tap-targets.spec.js` | цели нажатия в подвале, гармошка, перекрытие кнопкой «наверх», семантика |

**Почему подвал попал сюда, а не в `ui/`.** Он проверяет не «нарисовано
ли», а «попадёт ли палец». Это разные вопросы: подвал был нарисован
правильно и при этом ссылки имели высоту 17 при норме 44.

## Как запускать

```bash
npm test                    # только desktop, быстрый прогон
npm run test:all            # все три проекта: desktop, tablet, mobile
npm run test:report         # открыть последний HTML-отчёт

npx playwright test tests/e2e/ux/                      # одна папка
npx playwright test tests/e2e/ux/19-footer-tap-targets.spec.js   # один набор
npx playwright test --list                             # что вообще найдено
```

**Проекты и их окна:**

| Проект | Окно |
|---|---|
| `desktop` | 1280 × 800 |
| `tablet` | 768 × 1024 |
| `mobile` | 375 × 812 |

**Известный пробел в проектах.** Ни один из трёх не покрывает **844**
(телефон горизонтально) и **1024** (планшет горизонтально) — а именно
там 20–21.09 нашлись два дефекта подряд: `h270` и `h274`. Оба жили
между 769 и 1280, куда ни один проект не заглядывает. Задача на будущее:
добавить `phone-landscape` 844×390 и `tablet-landscape` 1024×768.

**Что нужно для прогона.** Перед тестами поднимается
`python3 -m http.server 8000` — это делает сам Playwright по настройке
`webServer`. Ещё есть `globalSetup`: он логинится в Supabase, чтобы
проверить кабинет и админку. Без сети прогон не начнётся вовсе — так
задумано: молча уйти в боевую базу хуже, чем не запуститься.

## Рядом с тестами

`tools/check-footer.js` (он же `npm run check:footer`) — **не тест
Playwright**, а быстрая проверка по исходникам: 27 правил, доля секунды,
без браузера и базы. Она стережёт то, что добыто замерами, и запускается
перед коммитом. Полную отрисовку проверяет `ux/19-footer-tap-targets`.

Отчёты о прогонах — в `tests/reports/`.
