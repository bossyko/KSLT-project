# Уже применённые запросы

Здесь лежит то, что однажды прогнали на боевой базе: разовые заливки
данных, чистки и правила доступа. Повторно запускать их не нужно — часть
удаляет данные и при втором прогоне сотрёт то, что мы завели после.

Держим не ради запуска, а ради памяти: по этим файлам видно, откуда в
базе взялись корты, новости, турниры и рейтинг.

Что здесь:

| `courts-contacts.sql` | колонки под WhatsApp и Instagram, заполнение из реестра |
| `import-news.sql` | перенос новостей со старого сайта |
