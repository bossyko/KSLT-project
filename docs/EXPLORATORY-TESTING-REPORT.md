## 6. Рекомендации

### 6.1 Высокий приоритет
1. **Серверная фильтрация match_type** — заменить клиентский `.filter()` на `.neq('match_type', 'duel')` в запросах player.js и dashboard.js
2. **Кнопка "Восстановить"** в rejected tab — для исправления ошибочных отклонений

### 6.2 Средний приоритет
3. **Оптимистичное обновление UI** — при quick approve/reject убирать строку из таблицы без полной перезагрузки
4. **Оффлайн-режим PWA** — протестировать корректность Service Worker для новых страниц (challenge.html)

### 6.3 Низкий приоритет
5. **Удаление дублей в select** — `select('*, match_type, ...')` → `select('*, ...')`
6. **Console.log cleanup** — убрать debug логи перед production
