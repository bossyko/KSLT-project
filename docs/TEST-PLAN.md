# KSLT — Полный тест-план для ручного тестирования

> **Версия:** 2.0 | **Дата:** 2026-03-20
> **Цель:** Финальное ручное тестирование перед встречей с покупателем
> **Покрытие:** 17 секций, 200 тест-кейсов, все роли (Guest / Registered / Member / Manager / Admin)

---

## Тестовые данные

### Аккаунты

| Роль | Email | Членство | Описание |
|------|-------|----------|----------|
| Admin | admin@test.kslt.kg | active | Полный доступ |
| Manager | manager@test.kslt.kg | active | Ограниченный доступ к админке |
| Member | member@test.kslt.kg | active | Обычный член KSLT |
| Registered | user@test.kslt.kg | нет | Зарегистрирован, не член |
| Banned | banned@test.kslt.kg | — | Забаненный игрок |

### Окружение

- **URL:** `http://localhost:8000`
- **Браузеры:** Chrome (основной), Safari, Firefox
- **Устройства:** Desktop 1200px, Tablet 768px, Mobile 375px

---

## Формат тест-кейса

| Поле | Описание |
|------|----------|
| **ID** | Уникальный номер (TC-001 — TC-200) |
| **Название** | Краткое описание проверки |
| **Предусловие** | Что должно быть готово перед тестом |
| **Шаги** | Пронумерованные действия |
| **Ожидаемый результат** | Что должно произойти |
| **Роль** | Под какой ролью тестировать |
| **Приоритет** | P0 = критичный, P1 = важный, P2 = функциональный |
