## 1. Вход в админку

1. Войдите в свой аккаунт на сайте KSLT
2. В шапке сайта наведите на кнопку **«Админка»**
3. Выберите нужную секцию из выпадающего меню

> Кнопка «Админка» видна только менеджерам и администраторам.

### Доступ по ролям

| Секция | Менеджер | Администратор |
|--------|----------|---------------|
| Новости | Создание, редактирование, удаление | Полный доступ |
| Турниры | Создание, редактирование, удаление | Полный доступ |
| Корты | Создание, редактирование, удаление | Полный доступ |
| Тренеры | Создание, редактирование, удаление | Полный доступ |
| Игроки | Просмотр + бан/разбан игроков | + Результаты + CRUD |
| Пользователи | Просмотр + аналитика + бан/удаление обычных | + Роли + бан всех |
| Финансы | CRUD + статистика + PDF + Excel | Полный доступ |
| Ваучеры | Просмотр + статистика + PDF + Excel | + Отмена ваучеров |
| Настройки | — | Правила очков + Промоушен |

## 3. Новости (Контент)

### 3.1 Создание статьи

1. Перейдите в секцию **«Контент»** (Новости)
2. Нажмите **«+ Добавить статью»**

### 3.2 Заполнение формы

**Обложка:**
- Кликните на зону загрузки и выберите фото (JPG/PNG)
- Или перетащите файл в зону
- Или вставьте URL изображения и нажмите **«Применить»**

**Заголовок и Slug:**
- Введите заголовок на русском (RU) — основной язык
- **Slug** (URL-адрес) генерируется автоматически
- Переключайтесь между вкладками **RU / EN / KG** для перевода
- Кнопка **«Перевести»** автоматически переведёт текст

**Краткое описание:**
- Показывается в карточке статьи в списке новостей

**Текст статьи:**
- Поле **«Содержание»** — основной текст
- Абзацы разделяйте **пустой строкой** (Enter дважды)

**Метаданные:**
- **Категория** — Репортаж / Интервью / Анонс / Мировой теннис
- **Автор** — по умолчанию «KSLT Media»
- **Исполнитель** — ваше имя
- **Дата публикации** — выберите дату (пусто = черновик)

### 3.3 Фото в тексте

Под полем «Содержание» находится блок **«Предпросмотр»**.

1. Между абзацами видны кнопки **«+ Фото»** и **«URL»**
2. **«+ Фото»** — выберите файл с компьютера
3. **«URL»** — вставьте ссылку на изображение
4. Удалить фото: наведите на фото → нажмите **«×»**

### 3.4 Голосование

1. Найдите секцию **«Голосование»** в форме
2. Нажмите **«Добавить голосование»**
3. Введите вопрос и варианты ответов (минимум 2)
4. **«+ Добавить вариант»** — для дополнительных
5. **«Убрать голосование»** — удалить опрос

> Голосование анонимное. Читатель голосует один раз и видит результаты.

### 3.5 Автосохранение

- Статья **автоматически сохраняется** каждые 3 секунды
- Отметка: **«✓ Черновик сохранён 15:24»**
- Черновик появляется в списке со статусом **«Черновик»**

### 3.6 Публикация

1. Заполните все поля
2. Укажите дату публикации
3. Нажмите **«Опубликовать»**

## 4. Турниры

### 4.1 Создание турнира

1. Перейдите в секцию **«Турниры»**
2. Нажмите **«+ Добавить турнир»**

### 4.2 Заполнение формы

| Поле | Описание |
|------|----------|
| **Название (RU/EN/KG)** | 3 языка, кнопка «Перевести» |
| **Описание (RU/EN/KG)** | Подробное описание турнира |
| **Площадка** | Поиск корта из базы (автокомплит) |
| **Категория** | Tour / Futures / Challenger / Masters / Pro-Masters |
| **Формат** | Одиночный / Парный / Микст |
| **Уровень** | Кат.1 / Кат.2 / Кат.3 / Кат.4 / Grand |
| **Тип сетки** | Single Elimination / FIC / Round Robin |
| **Размер сетки** | 8 / 16 / 32 / 64 (для SE и FIC) |
| **Кол-во групп** | Только для Round Robin |
| **Макс. участников** | Ограничение заявок |
| **Призовой фонд** | Например: «100,000 сом» |
| **Даты регистрации** | Начало и конец приёма заявок |
| **Даты турнира** | Начало и конец турнира |

### 4.3 Типы турнирных сеток

| Тип | Описание | Когда использовать |
|-----|----------|--------------------|
| **Single Elimination** | Олимпийская система. Проигравший выбывает | Стандартные турниры 8–64 игроков |
| **FIC** | Main Draw + Consolation. Проигравшие в 1-м раунде — в утешительную | Турниры где важно больше матчей |
| **Round Robin** | Каждый играет с каждым в группе | Маленькие турниры, лиги |

### 4.4 Управление заявками

1. Откройте турнир → вкладка **«Заявки»**
2. Статус заявки: `pending` → `approved` → `draw`
3. **Одобрить** — игрок включён в список
4. **Отклонить** — заявка отменяется
5. Гендер-проверка: мужчина не попадёт на женский турнир
6. Лист ожидания: если категория не совпадает → статус `waitlist`

### 4.5 Жеребьёвка (Draw)

1. Перейдите во вкладку **«Сетка»**
2. Нажмите **«Сгенерировать жеребьёвку»**
3. Система автоматически расставит сеяных (ITF) и несеяных (Fisher-Yates)

### 4.6 Внесение результатов

1. Кликните на матч в сетке
2. Введите счёт по сетам (например: 6-3, 7-5)
3. Система определит победителя и продвинет в следующий раунд

### 4.7 Финализация

1. Нажмите **«Финализировать турнир»**
2. Система рассчитает очки по таблице `points_rules`
3. Рейтинг игроков обновится автоматически

### 4.8 Рассылка в Telegram

Кнопка **«Рассылка в Telegram»** в форме турнира — отправляет анонс в группу (только админ). Также работает автоматический cron: если дата начала регистрации = сегодня → рассылка.

## 5. Корты

### 5.1 Создание корта

1. Перейдите в секцию **«Корты»**
2. Нажмите **«+ Добавить корт»**

### 5.2 Заполнение формы

| Поле | Описание |
|------|----------|
| **Фото** | Загрузка файла или URL |
| **Название (RU/EN/KG)** | Кнопка «Перевести» |
| **Типы кортов** | Динамические строки: тип, покрытие, кол-во, цена, партнёр |
| **Адрес (RU/EN/KG)** | Улица, район, город |
| **Google Maps / 2GIS** | Ссылки на карты |
| **Удобства** | Чекбоксы: парковка, WiFi, кафе, освещение и др. |
| **Телефоны** | Мобильный + городской (формат: `555 12-34-56`) |

### 5.3 Типы кортов

Каждый корт может иметь несколько типов:
- **Тип** — Открытый / Закрытый / Мини
- **Покрытие** — Хард / Грунт / Трава / Ковёр
- **Кол-во / Цена / Партнёр KSLT**

### 5.4 Формат телефона

- Вводите **9 цифр** без кода: `555 12-34-56`
- Сохраняется как `+996555123456`
- Отображается: `+996 555 12-34-56`

## 7. Финансы

Секция **«Финансы»** — единый центр всех финансовых операций. Объединяет оплаты за корты, тренеров, членские взносы и спонсорские поступления.

### 7.1 Обзор таблицы

Каждая строка имеет **тип-бейдж**:

| Бейдж | Описание |
|-------|----------|
| **Членство** | Членский взнос (новое или продление) |
| **Корт** | Оплата за продвижение корта |
| **Тренер** | Оплата за продвижение тренера |
| **Клуб** | Спонсорские / грантовые поступления для KSLT |

**Колонки таблицы:**
- Плательщик — имя/название
- Тип — бейдж (Членство / Корт / Тренер / Клуб)
- Сумма — в KGS
- Активен до — дата окончания
- Способ оплаты — Наличные / Перевод / Карта
- Статус — Активна (зелёный) / Истекла (серый)
- Создано — дата создания записи (формат ДД.ММ.ГГ)

### 7.2 Создание оплаты — Членство

Для оформления нового членства или продления:

1. Нажмите **«+ Добавить оплату»** (кнопка sticky — остаётся видна при прокрутке)
2. В поле **«Тип объекта»** выберите **«Членство»**
3. В поле **«Пользователь»** начните вводить имя:
   - Поиск идёт по базе пользователей (profiles) и игроков (players)
   - Выберите нужного из выпадающего списка
4. Укажите **сумму** (0 допускается — см. ниже)
5. Выберите **срок членства**:
   - Кнопки-пресеты: **1 мес | 3 мес | 6 мес | 1 год** (автозаполнение даты окончания)
   - Или введите даты вручную через календарь
6. Выберите **способ оплаты**: Наличные / Перевод / Карта
7. При необходимости добавьте **примечание**
8. Нажмите **«Сохранить»**

**Бесплатное членство (0 сом):**
- Допускается при сумме 0
- Поле **«Примечание»** становится обязательным — укажите причину (например: «Победитель турнира», «Спонсорская акция»)

> При сохранении создаются две записи: в таблице `memberships` (членство) и `payments` (платёж). Оба отображаются в финансах.

### 7.3 Создание оплаты — Корт / Тренер

Для оплаты продвижения корта или тренера:

1. Нажмите **«+ Добавить оплату»**
2. Выберите тип: **«Корт»** или **«Тренер»**
3. Начните вводить название → выберите из автокомплита
4. Выберите **назначение**: Продвижение / Спонсорство / Аренда / Другое
5. Укажите сумму, валюту, период (дата начала → дата окончания)
6. Способ оплаты + примечание
7. **«Сохранить»**

### 7.4 Создание оплаты — Клуб (KSLT)

Для оприходования спонсорских или грантовых средств:

1. Нажмите **«+ Добавить оплату»**
2. Выберите тип: **«Клуб»**
3. В поле **«От кого»** впишите название спонсора / организации
4. Укажите **сумму**
5. Выберите **дату операции** (одна дата, не период)
6. Способ оплаты + примечание (для чего выделены средства)
7. **«Сохранить»**

### 7.5 Как работает Promoted

1. Создайте оплату с типом «Корт» или «Тренер» и назначением **«Продвижение»**
2. Укажите период (например: 01.03 → 31.03)
3. Пока дата окончания ≥ сегодня — значок ⭐ появляется у корта/тренера на сайте
4. Когда период истёк — значок автоматически исчезает

### 7.6 Фильтры

- **Дата** — Все / Этот месяц / Прошлый месяц / Свой период
- **Поиск** — по имени плательщика
- **Тип** — Все / Членство / Корт / Тренер / Клуб
- **Статус** — Все / Активна / Истекла

### 7.7 Статистика

Карточки в верхней части:
- **Активных** — оплаты с неистёкшим сроком
- **Истёкших** — просроченные
- **За этот месяц** — новых транзакций
- **Общая сумма** — сумма всех платежей (KGS)

### 7.8 График динамики оплат

Линейный график за последние 12 месяцев с 4 линиями:
- 💛 **Членство** — лаймовый (accent)
- 🟢 **Корт** — зелёный
- 🟡 **Тренер** — жёлтый
- 🔵 **Клуб** — синий

Наведите на точку — увидите сумму в KGS за конкретный месяц.

### 7.9 Редактирование и удаление

- **Кликните на строку** в таблице → откроется форма редактирования (для типов Корт / Тренер / Клуб)
- Кнопка **«Удалить»** — удалить транзакцию (необратимо, потребуется подтверждение)

> Членские платежи пока только для создания, редактирование через Финансы в разработке.

## 9. Пользователи и аналитика

### 9.1 Карточки статистики

**Верхний ряд (воронка):**
| Карточка | Описание |
|----------|----------|
| 👥 **Всего** | Зарегистрированных аккаунтов |
| 🎾 **Стали игроками** | Привязан player_id |
| 📊 **Конверсия** | % конверсии |
| 📈 **Новых** | За текущий месяц |

**Нижний ряд:**
| Карточка | Описание |
|----------|----------|
| 🏅 **Членов** | С активным членством |
| ✈️ **Telegram** | Привязали Telegram |
| 🗑️ **Удалено** | Удалённых аккаунтов |
| 🚫 **Забанено** | Заблокированных |

### 9.2 Фильтры

- **Период** — по дате регистрации
- **Поиск** — по имени или email
- **Роль** — Все / Админ / Менеджер / Пользователь
- **«Только пользователи»** — показывает тех, кто ещё не стал игроком. **«Показать всех»** — полный список

### 9.3 Карточка пользователя

Кликните на пользователя → откроется карточка:

- **Профиль**: ФИО, телефон, email, дата регистрации
- **Членство**: статус (Активно до ДД.ММ.ГГГГ / Нет членства) + ссылка «Управление в Финансах»
- **Категория игрока**: смена категории (если есть player_id)
- **Модерация**: бан/разбан

> Выдача и продление членства — через секцию **«Финансы»** (тип «Членство»).

### 9.4 Что может менеджер

- Просматривать список и карточки
- Экспортировать PDF и Excel отчёты
- **Банить / разбанивать** обычных пользователей (role = user)
- **Удалять** обычных пользователей

> Менеджер **не может** банить/удалять других менеджеров и администраторов.

## 13. Членство: полный цикл

### 13.1 Как работает членство

```
Регистрация на сайте → Оплата членства → Член клуба (полный доступ)
                                              ↓
                                     Уведомление за 7 дней
                                              ↓
                                     Истечение → status='expired'
                                              ↓
                                     Уведомление об истечении (TG + Email)
                                              ↓
                                     Ограниченный доступ (registered)
                                              ↓
                                     Продление → снова полный доступ
```

### 13.2 Два пути оформления

**Путь 1 — Менеджер вручную (админка):**
1. Финансы → + Добавить оплату → Членство
2. Найти пользователя → указать срок и сумму → Сохранить

**Путь 2 — Telegram бот (автоматически):**
1. Пользователь пишет `/membership` боту
2. Бот проводит через оплату
3. После подтверждения — членство и платёж создаются автоматически

### 13.3 Уровни доступа на сайте

| Уровень | Рейтинг | Профили игроков | Турниры | Вызовы |
|---------|---------|-----------------|---------|--------|
| **Гость** | 8 строк + blur | Нет | Нет | Нет |
| **Зарегистрированный** | Полный | Полный | Нет | Нет |
| **Член клуба** | Полный | Полный | Регистрация | Отправка |

### 13.4 Автоматические процессы

| Процесс | Время (Бишкек) | Что делает |
|---------|----------------|------------|
| Авто-истечение | 09:30 | Находит просроченные членства → status='expired' → TG + Email |
| Напоминание | 10:00 | Находит истекающие через 7 дней → TG + Email |
| Авто-разбан | 09:00 | Снимает истёкшие баны → TG уведомление |

### 13.5 Где видеть информацию о членствах

- **Дашборд** → таблицы «Просроченные» и «Истекающие»
- **Финансы** → фильтр «Членство» — все транзакции
- **Карточка пользователя** → статус членства (информационный)

## 14. Часто задаваемые вопросы

**Как оформить членство пользователю?**
Финансы → + Добавить оплату → тип «Членство» → найти пользователя → указать срок → Сохранить. Используйте пресеты (1/3/6/12 мес) для быстрого выбора.

**Как продлить членство?**
Так же через Финансы — создайте новую оплату с типом «Членство». Новое членство будет создано с указанными датами.

**Можно ли оформить бесплатное членство?**
Да, укажите сумму 0 и обязательно заполните примечание (причина: победитель турнира, акция и т.д.).

**Как записать спонсорские деньги?**
Финансы → + Добавить оплату → тип «Клуб» → вписать «От кого» → сумма → дата → в примечании указать назначение.

**Как сделать корт или тренера Promoted?**
Финансы → создать транзакцию с типом «Корт»/«Тренер» и назначением «Продвижение», указать период.

**Как экспортировать отчёт?**
Настройте фильтры → кнопка «📄 PDF» (новая вкладка для печати) или «📊 Excel» (скачивание .csv файла).

**Почему турнир не виден на сайте?**
Проверьте дату публикации. Без даты — это черновик.

**Что если членство истекло?**
Система автоматически: ставит status='expired', отправляет уведомление в TG и email. Пользователь теряет доступ к турнирам и вызовам, но может просматривать рейтинг.

**Что если я случайно удалил запись?**
Удаление необратимо. Система запрашивает подтверждение.

**Как проверить, активна ли оплата?**
В Финансах: зелёный бейдж «Активна» / серый «Истекла». Фильтр по статусу для удобства.

**Что означает «Только пользователи» в секции Пользователи?**
Показывает только тех, кто зарегистрирован на сайте, но ещё не имеет карточки игрока в рейтинговой системе. «Показать всех» — полный список.

**Как работают уведомления?**
Автоматически: за 7 дней до истечения + при истечении. Пользователь может отключить в Настройках или через /notifications в Telegram боте. Баны всегда отправляются.
