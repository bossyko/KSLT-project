## 1. Вход в админку

1. Войдите в свой аккаунт на сайте KSLT
2. В шапке сайта наведите на кнопку **«Админка»**
3. Выберите нужную секцию из выпадающего меню или кликните на кнопку для перехода в панель

> Кнопка «Админка» видна только менеджерам и администраторам.

### Доступ менеджера

| Секция | Менеджер | Администратор |
|--------|----------|---------------|
| Новости | Создание, редактирование, удаление | Полный доступ |
| Турниры | Создание, редактирование, удаление | Полный доступ |
| Корты | Создание, редактирование, удаление | Полный доступ |
| Тренеры | Создание, редактирование, удаление | Полный доступ |
| Игроки | Список + Рейтинг (просмотр) + бан/разбан игроков | + Результаты + CRUD |
| Пользователи | Просмотр + воронка + аналитика + PDF + бан/удаление обычных | + Роли + бан/удаление всех |
| Финансы | CRUD + статистика + PDF | Полный доступ |
| Ваучеры | Просмотр + статистика + PDF | + Отмена ваучеров |
| Настройки | — | Правила очков + Промоушен |

## 2. Новости (Контент)

### 2.1 Создание статьи

1. Перейдите в секцию **«Контент»** (Новости)
2. Нажмите **«+ Добавить статью»**

### 2.2 Заполнение формы

**Обложка:**
- Кликните на зону загрузки и выберите фото (JPG/PNG)
- Или перетащите файл в зону
- Или вставьте URL изображения и нажмите **«Применить»**

**Заголовок и Slug:**
- Введите заголовок на русском (RU) — основной язык
- **Slug** (URL-адрес) генерируется автоматически
- Переключайтесь между вкладками **RU / EN / KG** для перевода
- Кнопка **«Перевести»** автоматически переведёт текст

**Краткое описание:**
- Показывается в карточке статьи в списке новостей

**Текст статьи:**
- Поле **«Содержание»** — основной текст
- Абзацы разделяйте **пустой строкой** (Enter дважды)

**Метаданные:**
- **Категория** — Репортаж / Интервью / Анонс / Мировой теннис
- **Автор** — по умолчанию «KSLT Media»
- **Исполнитель** — ваше имя
- **Дата публикации** — выберите дату (пусто = черновик)

### 2.3 Фото в тексте

Под полем «Содержание» находится блок **«Предпросмотр»**.

1. Между абзацами видны кнопки **«+ Фото»** и **«URL»**
2. **«+ Фото»** — выберите файл с компьютера
3. **«URL»** — вставьте ссылку на изображение
4. Удалить фото: наведите на фото → нажмите **«×»**

```
Абзац 1: Вчера состоялся турнир...
         [+ Фото]  [URL]
──────────────────────────
  [ фото турнира ]    [×]
──────────────────────────
         [+ Фото]  [URL]
Абзац 2: В финале встретились...
```

### 2.4 Голосование

1. Найдите секцию **«Голосование»** в форме
2. Нажмите **«Добавить голосование»**
3. Введите вопрос и варианты ответов (минимум 2)
4. **«+ Добавить вариант»** — для дополнительных
5. **«Убрать голосование»** — удалить опрос

> Голосование анонимное. Читатель голосует один раз и видит результаты.

### 2.5 Автосохранение

- Статья **автоматически сохраняется** каждые 3 секунды
- Отметка: **«✓ Черновик сохранён 15:24»**
- Черновик появляется в списке со статусом **«Черновик»**

### 2.6 Публикация

1. Заполните все поля
2. Укажите дату публикации
3. Нажмите **«Опубликовать»**
4. Статья сразу появится на сайте

## 3. Турниры

### 3.1 Создание турнира

1. Перейдите в секцию **«Турниры»**
2. Нажмите **«+ Добавить турнир»**

### 3.2 Заполнение формы

| Поле | Описание |
|------|----------|
| **Название (RU/EN/KG)** | 3 языка, кнопка «Перевести» |
| **Описание (RU/EN/KG)** | Подробное описание турнира |
| **Площадка** | Поиск корта из базы (автокомплит) |
| **Категория** | Tour / Futures / Challenger / Masters / Pro-Masters |
| **Формат** | Одиночный / Парный / Микст |
| **Уровень** | Кат.1 / Кат.2 / Кат.3 / Кат.4 / Grand |
| **Тип сетки** | Single Elimination / FIC / Round Robin |
| **Размер сетки** | 8 / 16 / 32 / 64 (для SE и FIC) |
| **Кол-во групп** | Только для Round Robin |
| **Макс. участников** | Ограничение заявок |
| **Призовой фонд** | Например: «100,000 сом» |
| **Даты регистрации** | Начало и конец приёма заявок |
| **Даты турнира** | Начало и конец турнира |

### 3.3 Типы турнирных сеток

| Тип | Описание | Когда использовать |
|-----|----------|--------------------|
| **Single Elimination (SE)** | Классическая олимпийская система. Проигравший выбывает | Стандартные турниры 8–64 игроков |
| **FIC** | Две сетки: Main Draw + Consolation. Проигравшие в 1-м раунде переходят в утешительную сетку | Турниры где важно дать больше матчей |
| **Round Robin (RR)** | Групповой этап — каждый играет с каждым внутри группы | Маленькие турниры, лиги |

### 3.4 Управление заявками

После создания турнира откройте его и перейдите во вкладку **«Заявки»**:

1. **Новые заявки** приходят от игроков через публичную страницу турнира
2. Статус заявки: `pending` → `approved` → `draw`
3. **Одобрить** — игрок включён в список участников
4. **Отклонить** — заявка отменяется
5. Когда все заявки обработаны — переходите к жеребьёвке

### 3.5 Жеребьёвка (Draw)

Перейдите во вкладку **«Сетка»**:

1. Нажмите **«Сгенерировать жеребьёвку»**
2. Система автоматически:
   - Расставит сеяных игроков по позициям ITF
   - Распределит несеяных случайным образом (Fisher-Yates)
   - Создаст все матчи первого раунда
3. Сетка отображается визуально — вы можете проверить расстановку

> Для FIC-турниров создаются две сетки: Main Draw и Consolation.

### 3.6 Внесение результатов

Для каждого матча в сетке:

1. Кликните на матч
2. Откроется модальное окно с полями для сетов
3. Введите счёт (например: 6-3, 7-5)
4. Система автоматически определит победителя
5. Победитель переходит в следующий раунд (`advanceWinner`)

### 3.7 Финализация турнира

Когда все матчи завершены:

1. Нажмите **«Финализировать турнир»**
2. Система автоматически:
   - Рассчитает очки по таблице `points_rules` для каждого участника
   - Обновит рейтинг игроков (`recalcPlayerPoints`)
   - Выставит итоговый статус турнира
3. Очки начисляются в зависимости от:
   - Уровня турнира (Кат.1–Grand)
   - Раунда выбывания (1R, 2R, QF, SF, F, W)

### 3.8 Поиск турниров

На публичных страницах турниров работает поиск по названию:
- **Обзор категорий** — поиск по всем турнирам всех категорий
- **Страница категории** — поиск внутри выбранной категории + фильтр по статусу

## 4. Корты

### 4.1 Создание корта

1. Перейдите в секцию **«Корты»**
2. Нажмите **«+ Добавить корт»**

### 4.2 Заполнение формы

| Поле | Описание |
|------|----------|
| **Фото** | Загрузка файла или URL |
| **Название (RU/EN/KG)** | Кнопка «Перевести» |
| **Типы кортов** | Динамические строки: тип, покрытие, кол-во, цена, партнёр |
| **Адрес (RU/EN/KG)** | Улица, район, город, индекс |
| **Google Maps** | Ссылка (показывается карта в превью) |
| **2GIS** | Ссылка на 2ГИС |
| **Удобства** | Чекбоксы: парковка, WiFi, кафе, освещение и др. |
| **Телефоны** | Мобильный + городской (формат: `555 12-34-56`) |
| **Контакты** | Имя контактного лица |

### 4.3 Типы кортов

Каждый корт может иметь несколько типов (строк):
- **Тип** — Открытый / Закрытый / Мини
- **Покрытие** — Хард / Грунт / Трава / Ковёр
- **Кол-во кортов** — Число
- **Цена** — За час аренды
- **Партнёр KSLT** — Отметка о партнёрстве

### 4.4 Формат телефона

- Вводите **9 цифр** без кода страны: `555 12-34-56`
- Система автоматически сохраняет как `+996555123456`
- На публичной странице отображается: `+996 555 12-34-56`

## 6. Финансы

Секция **«Финансы»** объединяет все финансовые операции в одну таблицу: оплаты за Promoted (корты/тренеры) и членские взносы.

### 6.1 Что показывает таблица

Каждая строка имеет **тип-бейдж**:
- **Корт** — оплата за продвижение корта
- **Тренер** — оплата за продвижение тренера
- **Членство** — членский взнос

### 6.2 Создание транзакции

1. Перейдите в секцию **«Финансы»**
2. Нажмите **«+ Добавить транзакцию»**
3. Выберите **тип**: Корт / Тренер

### 6.3 Заполнение формы

| Поле | Описание |
|------|----------|
| **Тип сущности** | Корт / Тренер |
| **Название** | Поиск по имени (автокомплит) |
| **Назначение** | Promoted / Спонсорство / Аренда / Другое |
| **Сумма** | Число |
| **Валюта** | По умолчанию KGS |
| **Период** | Дата начала → Дата окончания |
| **Способ оплаты** | Наличные / Перевод / Карта |
| **Заметка** | Внутренний комментарий |

### 6.4 Как работает Promoted

1. Создайте оплату с назначением **«Promoted»**
2. Укажите период действия (например: 01.03 → 31.03)
3. Пока дата окончания ≥ сегодня — статус **Активный** (зелёный)
4. Когда дата окончания прошла — статус **Истёкший** (серый)
5. Promoted-значок (⭐) автоматически появляется/исчезает в формах кортов и тренеров

### 6.5 Фильтры

- **Тип** — Все / Членство / Промоушен
- **Поиск** — по имени
- **Период** — Всё время / Этот месяц / Прошлый месяц / Свой период

### 6.6 Статистика

В верхней части секции отображаются карточки:
- **Активных** оплат
- **Истёкших** оплат
- **Новых** за этот месяц
- **Общая сумма** — сумма всех платежей за выбранный период

Доступен **фильтр периода** и **экспорт PDF** (см. раздел [10. Отчёты](#10-отчёты-и-pdf-экспорт)).

## 7. Ваучеры

Секция **«Ваучеры»** показывает все скидочные ваучеры, которые генерируются участниками с активным членством.

### 7.1 Дашборд

В верхней части секции два блока статистики:

**Большие карточки (2):**
- **Всего выдано** — общее количество ваучеров
- **Общая сумма скидок** — рассчитывается из цен кортов/тренеров × процент скидки

**Малые карточки (3):**
- **Использовано** — ваучеры со статусом `used` (с процентом конверсии)
- **Активных** — неиспользованные и не истёкшие
- **Истекло** — просроченные ваучеры

### 7.2 Фильтры и таблица

| Фильтр | Описание |
|--------|----------|
| **Период** | Всё время / Этот месяц / Прошлый месяц / Свой период |
| **Поиск** | По имени игрока |
| **Статус** | Все / Активные / Использованные / Истёкшие / Отменённые |
| **Тип услуги** | Все / Корты / Тренеры |
| **Сортировка** | По дате / По имени / По статусу |

**Таблица содержит:**
- Порядковый номер, ФИО игрока, Корт/Тренер, Тип услуги, Скидка (%), Дата, Статус, Действия

### 7.3 Действия

- **Просмотр** (👁) — детальная информация о ваучере (модальное окно)
- **Отмена** (✕) — отменить активный ваучер (**только администратор**)

### 7.4 PDF-отчёт

Кнопка **«📄 PDF»** открывает отчёт в новой вкладке для печати/сохранения.

## 8. Пользователи и аналитика

Секция **«Пользователи»** показывает всех зарегистрированных на сайте, с подробной аналитикой.

### 8.1 График динамики

В верхней части — **график за текущий месяц** (Chart.js):
- **Ось X** — дни месяца (1, 2, 3, ... сегодня)
- **4 линии:**
  - 🟢 Зелёная — зарегистрировано (кумулятивно)
  - 🟡 Жёлтая — стали игроками (кумулятивно)
  - 🔴 Красная — удалено (кумулятивно)
  - 💛 Лаймовая — чистый прирост

### 8.2 Карточки статистики

**Верхний ряд (воронка конверсии):**

| Карточка | Описание |
|----------|----------|
| 👥 **Всего** | Общее количество зарегистрированных аккаунтов |
| 🎾 **Стали игроками** | Привязан `player_id` — конвертировались в членов KSLT |
| 📊 **Конверсия** | Процент конверсии (игроки / всего) |
| 📈 **Новых** | Новых регистраций за текущий месяц |

**Нижний ряд (детали):**

| Карточка | Описание |
|----------|----------|
| 🏅 **Членов** | С активным членством |
| ✈️ **Telegram** | Привязали Telegram аккаунт |
| 🗑️ **Удалено** | Удалённых аккаунтов |
| 🚫 **Забанено** | Заблокированные пользователи |

### 8.3 Фильтры

- **Период** — фильтрация таблицы по дате регистрации
- **Поиск** — по имени или email
- **Роль** — Все / Админ / Менеджер / Пользователь
- **Toggle «Только без игрока»** — по умолчанию скрывает пользователей, которые стали игроками. Нажмите «Показать всех» для полного списка

### 8.4 Что может менеджер

- Просматривать список пользователей и карточку каждого
- Видеть аналитику и статистику
- Экспортировать PDF-отчёт
- **Банить / разбанивать обычных пользователей** (role = user)
- **Удалять обычных пользователей** (role = user)

> Менеджер **не может** банить или удалять других менеджеров и администраторов.

**Только администратор:**
- Менять роли (user → manager)
- Создавать менеджеров
- Банить / разбанивать менеджеров
- Удалять менеджеров

## 9. Секции только для просмотра

Менеджер может просматривать, но **не может** редактировать:

| Секция | Что видно |
|--------|-----------|
| **Игроки → Список** | Карточки игроков рейтинговой системы (ФИО, категория, очки, W/L) |
| **Игроки → Рейтинг** | Таблица рейтинга по категориям и полу |
| **Настройки** | Недоступна для менеджера (только админ) |

### 9.1 Блокировка игроков

Менеджер и администратор могут заблокировать игрока за нарушение правил:

1. Откройте карточку игрока в секции **«Игроки»**
2. В нижней части формы найдите секцию **«Модерация»**
3. Нажмите **«Заблокировать игрока»**
4. Выберите срок: 7 дней / 30 дней / 90 дней / 1 год / Навсегда / Произвольная дата
5. Укажите причину (необязательно)
6. Нажмите **«Заблокировать»**

**Последствия блокировки:**
- Игрок **не может** регистрироваться на турниры (на сайте и через Telegram)
- Красный бейдж **«Заблок.»** виден в списке игроков и на публичной странице рейтинга
- Игроку приходит **уведомление в Telegram** с датой и причиной бана

**Разблокировка:**
- В карточке забаненного игрока нажмите **«Разблокировать»**
- Подтвердите действие
- Игроку придёт **уведомление** «Вы разблокированы»

## 10. Отчёты и PDF-экспорт

Во всех секциях с аналитикой (Ваучеры, Финансы, Пользователи) доступны:

### 10.1 Фильтр периода

| Период | Описание |
|--------|----------|
| **Всё время** | Все записи без ограничений |
| **Этот месяц** | С 1-го числа текущего месяца |
| **Прошлый месяц** | Весь прошлый месяц |
| **Свой период** | Выберите даты «С» и «По», нажмите «Применить» |

При смене периода **пересчитываются все карточки статистики** и фильтруется таблица.

### 10.2 Экспорт PDF

1. Настройте нужный период и фильтры
2. Нажмите кнопку **«📄 PDF»**
3. Откроется новая вкладка с отчётом
4. Браузер предложит **«Печать»** → выберите **«Сохранить как PDF»**

**Содержимое PDF-отчёта:**
- Заголовок: «KSLT — [Тип отчёта]»
- Период: даты фильтрации
- Статистика: ключевые показатели
- Таблица: все записи за период
- Подвал: итоги + дата генерации отчёта

> PDF-отчёт содержит **только отфильтрованные данные** — то, что вы видите в таблице.

### 10.3 Карточки статистики по секциям

| Секция | Карточки |
|--------|----------|
| **Финансы** | Активных, Истёкших, Новых за месяц, Общая сумма |
| **Ваучеры** | Всего выдано, Сумма скидок, Использовано, Активных, Истекло |
| **Пользователи** | Всего, Стали игроками, Конверсия %, Новых + Членов, Telegram, Удалено, Забанено |

## 11. Общие функции

### 11.1 Массовое удаление

1. Отметьте чекбоксы напротив нужных записей
2. Чекбокс в шапке таблицы — выделить все на странице
3. Появится кнопка **«Удалить выбранные (N)»**
4. Подтвердите удаление в диалоговом окне

### 11.2 Поиск и фильтры

- **Поиск** — по названию/имени (задержка 300мс для оптимизации)
- **Фильтры** — выпадающие списки по категории, статусу и другим параметрам
- Фильтры **sticky** — остаются видимыми при прокрутке таблицы
- При смене фильтра страница пагинации сбрасывается на 1

### 11.3 Автоперевод

- Кнопка **🌐 «Перевести»** переводит текст с заполненного языка на остальные
- Работает для: названий, описаний, должностей, достижений
- Проверяйте результат — автоматический перевод может быть неточным

### 11.4 Пагинация

- Таблицы показывают по 15 записей на странице
- Навигация: кнопки **« Назад** / номера страниц / **Далее »**
- Общее количество записей отображается рядом

## 12. Часто задаваемые вопросы

**Как сделать корт или тренера Promoted?**
Через секцию «Финансы» → создать транзакцию с типом «Корт» или «Тренер» и назначением «Promoted», указать период.

**Как создать FIC-турнир?**
При создании турнира выберите тип сетки «FIC» и размер сетки. Система автоматически создаст Main Draw + Consolation при жеребьёвке.

**Почему турнир не виден на сайте?**
Проверьте, что у турнира указана дата публикации (`published_at`). Без неё турнир считается черновиком.

**Как начислить очки рейтинга?**
Очки начисляются автоматически при финализации турнира. Правила начисления настраивает администратор.

**Что если я случайно удалил запись?**
Удаление необратимо. Перед массовым удалением система запрашивает подтверждение.

**Как добавить корт с несколькими типами покрытия?**
В форме корта нажмите **«+ Добавить тип корта»** — появится новая строка для типа, покрытия, количества и цены.

**Как проверить, активна ли оплата?**
В секции «Финансы» активные оплаты отмечены зелёным бейджем «Активный», истёкшие — серым «Истёкший». Используйте фильтр по типу для удобства.

**Как экспортировать отчёт в PDF?**
В любой секции с аналитикой (Ваучеры, Финансы, Пользователи) настройте нужный период и фильтры, затем нажмите кнопку «📄 PDF». Откроется новая вкладка — выберите «Сохранить как PDF» в диалоге печати.

**Что означают карточки статистики в секции «Пользователи»?**
Верхний ряд — **воронка конверсии**: всего зарегистрировано → стали игроками KSLT → процент конверсии → новых за месяц. Нижний ряд — детали: активных членов, Telegram, удалённых, забанено. График показывает 4 линии за текущий месяц: регистрации, конверсии в игроков, удаления, прирост. Таблица по умолчанию скрывает тех, кто уже стал игроком (toggle «Показать всех»).

**Можно ли отменить ваучер?**
Отменить активный ваучер может только администратор. Менеджер может просматривать ваучеры и экспортировать отчёты, но не может отменять.

**Что такое «Удалённые аккаунты»?**
Когда пользователь удаляет свой аккаунт, система сохраняет основные данные (ФИО, email, роль, наличие членства) для аналитики. Это позволяет отслеживать отток пользователей.
